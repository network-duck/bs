User Security (MySQL CLI)
Change root password and don’t use root account. Delete bad users.
Use mysql database: USE mysql
Show users: SELECT host, user FROM user;
Change password: alter user 'root'@'localhost' identified by 'newpass';
Remove user: DROP USER 'username'@'host';
FLUSH PRIVILEGES;
Look up the Digital Ocean guide… Just keep your firewall blocking it and bind to 0.0.0.0.

# Secure Installation
sudo mysql_secure_installation
# Connect to local server
mysql -u username -p
# List host/user combos
SELECT user,host FROM mysql.user;
# Change password (WARNING: This plaintext password will show up in ~/.mysql_history)
SET PASSWORD FOR ‘user’@’host’ = PASSWORD(‘password’);
# Create user (WARNING: This plaintext password will show up in ~/.mysql_history)
CREATE USER ‘user’@’host’ IDENTIFIED BY ‘password’;
# View privileges of a user
SHOW GRANTS FOR ‘user’@’host’;
# Grant Privileges
GRANT ALL ON db_name.* TO ‘user’@’host’;
GRANT CREATE,SELECT,INSERT,UPDATE,DELETE ON db_name.* to ‘user’@’host’;
# Revoke Privileges
REVOKE ALL, GRANT OPTION FROM ‘user’@’host’;
REVOKE DROP,DELETE ON db_name.* FROM ‘user’@’host’;
#Drop user
DROP USER &#39;user&#39;@&#39;host&#39;;
# Emergency Access (Be careful, this disables passwords)
/etc/init.d/mysql stop
mysqld --skip-grant-tables &amp;
/etc/init.d/mysql restart
# Backup databases
Dump entire database: mysqldump -u username -p -A &gt; backup.sql
Dump single database: mysqldump -u username -p -B db_name &gt; db_name.sql
# Restore databases
mysql -u username -p &lt; backup.sql
