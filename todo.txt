pg_hba.conf: (In postgres’s home directory)
● Restrictions on client IP’s
● &lt;|conn_type|&gt; &lt;|database(s)|&gt; &lt;|user(s)|&gt; &lt;|network|&gt; &lt;|auth_method|&gt;
● conn_type
○ local: Unix socket connections
○ host: Network connections
● database(s)
○ db1,db2,db3
○ all
● user(s)
○ user1,user2,user3
○ all
● network
○ network/cidr
○ &lt;blank&gt; # For Unix sockets
● auth_method
○ peer - check that the system username matches the postgresql username
○ md5 - MD5 hashed password
○ trust - Allow login w/o password
○ reject - Reject all connections

psql:
● Authentication
○ By default, users connecting via Unix sockets are authenticated by
checking that the system user is the same as the database user.
○ If connecting via the network, a password is required
● Superuser: postgres
○ postgres is the superuser, and by default cannot be logged in as via
the network
■ su postgres

● psql
○ psql [-U &lt;|username|&gt;] [-h &lt;|ip_addr|&gt;] [-d &lt;|dbname|&gt;]
○ By default -U is set to the current system username
○ By default -d is set to the given username
○ Additional options:
■ Execute the given command: -c “&lt;|cmd|&gt;”
■ Execute commands from the given file: -f &lt;|file|&gt;

● Commands

○ Informational Commands
■ Command help: \?
■ Exit: \q
■ List databases: \l # Lowercase L
■ Select a database: \c &lt;|db_name|&gt;
■ Show tables: \dt
■ Show roles: \du
■ Show privileges: \dp
○ View roles and passwords. (postgresql uses roles instead of users)
\c template1
SELECT * FROM pg_shadow;
○ User management
■ Create user: CREATE USER &lt;|user|&gt; WITH PASSWORD
‘&lt;|password|&gt;’;
■ Change pass: ALTER USER &lt;|user|&gt; WITH PASSWORD
‘&lt;|new_password|&gt;’;
■ Delete user: DROP USER &lt;|user|&gt;;
○ Privileges
■ Show privileges: \dp (per database)
■ Grant privileges (\c to the database)
■ Table: GRANT &lt;|privilege|&gt; ON &lt;|table|&gt; TO &lt;|user|&gt;;
■ Database: GRANT ALL ON ALL TABLES IN SCHEMA
PUBLIC TO &lt;|user|&gt;;
■ Revoke privileges
■ Table: REVOKE &lt;|privilege|&gt; ON &lt;|table|&gt; FROM &lt;|user|&gt;;
■ Database: REVOKE ALL ON ALL TABLES IN SCHEMA
PUBLIC FROM &lt;|user|&gt;;

■ There is also the PUBLIC role which is granted to all users
● Identifiable in \dp as ‘=&lt;|perms|&gt;’ (i.e. no username)

● Backup and Restore
○ Dump all: pg_dumpall &gt; backup.pgsql
○ Dump single db: pg_dump &lt;|db_name|&gt; &gt; &lt;|db_name|&gt;.pgsql
○ Restore: psql -f backup.pgsql
